Set up the shared database

This is the only setup anyone has to do, you do it once, it costs nothing, and nobody you invite needs an account of any kind — they just open the link and type a name.

  1. Go to console.firebase.google.com and sign in with your Google account. Press Create a project, name it marchland, and turn Google Analytics off when it offers.
  2. In the left sidebar choose Build → Realtime Database, press Create Database, pick the location nearest you, and choose Start in test mode.
  3. Copy the database URL it shows you at the top — it looks like https://marchland-1234-default-rtdb.firebaseio.com.
  4. Open this file in a text editor, find the line near the top that reads var DB_URL = ""; and paste the URL between the quotes. Save.
  5. Put the file online so your opponent can reach it — a free GitHub Pages repo, Netlify or Cloudflare Pages all work. Send them the link.

Two things worth knowing. Test mode leaves the database open to anyone who has the URL, which is fine for a game between people who trust each other and wrong for anything else — Firebase will email you in 30 days to say the rules are about to expire, and you can set them to {"rules":{"marchland":{".read":true,".write":true}}} to keep it as is. And because the board lives in your database, a determined player could edit their own step count. Between family that is a social problem, not a technical one; the notes on real anti-cheat are in the design document.
